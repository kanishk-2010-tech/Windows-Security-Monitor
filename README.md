# Windows Security Monitor

A Python-based Windows security monitoring system that continuously monitors system resources, running processes, network connections, and listening ports.

## Project Overview

Windows Security Monitor is a lightweight security monitoring application developed using Python.

The system collects information from a Windows computer and analyzes it for potentially suspicious changes such as:

- High CPU usage
- High RAM usage
- New listening ports
- New processes
- Network connections
- Security-related events

Detected events are recorded in a local SQLite database and displayed through a graphical dashboard.

## Objectives

1. Monitor Windows system resources.
2. Monitor running processes.
3. Monitor network connections.
4. Detect newly opened listening ports.
5. Maintain security baselines.
6. Generate security alerts.
7. Calculate a rule-based threat score.
8. Store security events in a database.
9. Provide a graphical security dashboard.
10. Export security events as CSV.

### Threat Assessment

The system calculates a rule-based threat score based on detected security events.

| Score | Threat Level |
|------:|--------------|
| 0–29 | LOW |
| 30–59 | MEDIUM |
| 60–79 | HIGH |
| 80–100 | CRITICAL |

The threat score is an indicator generated by project rules and does not automatically prove that a cyber attack has occurred.

## Baseline System

The project uses a baseline mechanism to identify changes.

During the initial run, the system records known listening ports and running processes.

These records are stored in JSON files.

During later monitoring cycles, the current system state is compared with the baseline.

If a previously unknown port or process appears, the system can generate a security alert.

## Threat Scoring

The project uses a rule-based scoring system.

Examples:

- High CPU usage increases the score.
- High RAM usage increases the score.
- A new listening service increases the score.
- High-severity events add additional weight.

The final score is limited to 100.

Example:

Threat Score : 30/100  
Threat Level : MEDIUM  

## How to Run

### 1. Check Python

Open CMD in the project folder and run:

python --version

### 2. Install dependency

Run:

pip install psutil

### 3. Start Security Monitor

Run:

python monitor.py

The monitor displays:

- System status
- Running processes
- Network connections
- Listening ports
- Security alerts
- Threat assessment

Press CTRL+C to stop the monitor.

### 4. Start Dashboard

Run:

python dashboard.py

The dashboard displays security information in a graphical interface.

## Limitations

This project is a monitoring and learning tool.

It does not:

- Guarantee detection of every cyber attack
- Replace professional endpoint security software
- Automatically determine whether a process is malicious
- Perform complete malware analysis
- Provide enterprise-level security monitoring

A detected event should therefore be investigated instead of automatically being considered malicious.

## Conclusion

Windows Security Monitor demonstrates how Python can be used to build a basic host-based security monitoring system.

The project combines system monitoring, process monitoring, network monitoring, baseline comparison, security alerts, threat scoring, database storage, and a graphical dashboard into a single application.

It provides a practical introduction to cybersecurity monitoring concepts and demonstrates how system-level information can be collected and analyzed on a Windows computer.

## Disclaimer

This project is intended for educational, defensive, and authorized security monitoring purposes only.

It should be used only on systems that the user owns or has permission to monitor.
